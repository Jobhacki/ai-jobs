# Contributing to the AI and machine learning jobs list

Help people find roles where AI or machine learning is central to the work. Please check the employer's description before suggesting a job.

## What belongs in this list

Machine learning engineering, AI research, model evaluation, and applied AI building roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and the AI or machine learning work described.

[Open the Add a job form](https://github.com/Jobhacki/ai-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the AI role title, employer, link, and whether the posting is unavailable or marked filled.

[Open the Report a dead link form](https://github.com/Jobhacki/ai-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
